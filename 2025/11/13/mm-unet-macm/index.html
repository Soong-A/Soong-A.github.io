MACM：让卷积适应不均匀的 3D 空间

发表于2025-11-13|更新于2026-10-11|学习笔记
|浏览量:

阅读约 7 分钟

English version: MACM: factorising the kernel

3D MRI 并不是由完全等距的立方体组成。前列腺 MR 常见的情况是：切片平面内分辨率较高，切片之间的间距却更大。MACM 因此不使用一个各方向完全相同的立方卷积核，而是把平面内信息与跨切片信息分开处理。

模块先做多尺度，再做融合

flowchart TD
  A[输入特征] --> B[1x1x1 卷积调整通道]
  B --> C[ACB：k 等于 3]
  B --> D[ACB：k 等于 7]
  B --> E[ACB：k 等于 13]
  B --> F[ACB：k 等于 15]
  B --> G[拼接调整后的输入与所有分支输出]
  C --> G
  D --> G
  E --> G
  F --> G
  G --> H[1x1x1 卷积融合并设置输出通道]
  H --> I[输出特征]

这不是把原输入与多尺度结果做一次简单残差相加。论文描述的是把输入与四个 ACB 分支的结果连接起来，再用 1×1×1 卷积完成融合与通道整理。这样，每个尺度的信息都被显式保留下来。

小卷积核偏向局部边缘和纹理，大卷积核覆盖更宽的器官形状与邻近结构。四个尺度同时存在，是为了避免只用一个固定感受野来解释大小和形态会变化的前列腺。

一个 ACB 里有两个方向

flowchart TD
  A[ACB 输入] --> B[1x1xk 卷积：沿切片方向]
  A --> C[kxkx1 卷积：在切片平面内]
  B --> D[两条分支逐元素相加]
  C --> D
  D --> E[ACB 输出]

1×1×k：跨切片

这一支只沿深度轴展开，重点观察相邻切片之间的连续变化。它帮助网络追踪前列腺从底部到顶部时形状如何改变，也能减少相邻切片预测边界忽然跳动的问题。

k×k×1：切片内

这一支在单张切片的平面上扩大感受野，关注局部纹理、轮廓以及前列腺与周围组织的关系。深度方向保持为 1，因此不会把粗糙的层间分辨率当成与平面内完全相同。

两条支路输出尺寸一致，所以可以相加。这里的“各向异性”不是一个装饰性名词，而是把 MRI 三个方向不同的物理间距直接反映到卷积核形状中。

为什么大卷积核还可以接受

直接使用 k×k×k 卷积时，单个输入—输出通道对需要 k³ 个权重。把不同方向拆开后，成本可以显著降低。

形式 核的结构 单通道参数量的量级
标准 3D 卷积 k×k×k k³
各向异性双分支 1×1×k 与 k×k×1 k + k²
三轴分解 k×1×1、1×k×1、1×1×k 3k

论文还讨论了把大 3D 卷积分解为沿三个轴的卷积组合。要注意：3k 是这种三轴分解的参数量，不应直接拿来描述上面 ACB 的两条并行分支。把这两件事分开，计算逻辑才不会混乱。

MACM 在 MM-UNet 里做什么

AFFM 先筛选并融合编码器细节与解码器语义；MACM 随后在多个尺度上整理这份融合特征，让它同时满足两种需求：在切片内精确定位边界，在切片之间保持三维连续性。

我会用下面的顺序记住它：

  1. 用 1×1×1 卷积控制通道。
  2. 把同一输入送入四个不同尺度的 ACB。
  3. 每个 ACB 再把平面内与跨切片信息分开建模。
  4. 拼接原输入与四个尺度的输出。
  5. 用最后的 1×1×1 卷积完成融合。

MACM 的核心不是“卷积核越大越好”，而是让卷积核的方向与尺度都对应真实的体数据几何。
