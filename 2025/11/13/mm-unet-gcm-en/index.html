GCM: global context through Mamba

发表于2025-11-13|更新于2026-10-11|English Notes
|浏览量:

8 min read

中文版：GCM：用 Mamba 建立全局视野

Detailed notes on MM-UNet’s Global Context-aware Module. It combines a CNN’s local feature extraction with Mamba’s long-sequence modelling to capture global context efficiently.

Overall structure

flowchart TD
  A[Input feature map B C H W D] --> B[Residual block one: Conv IN LeakyReLU]
  B --> C[Residual block two: Conv IN LeakyReLU]
  C --> D[Reshape to sequence B L C where L equals H times W times D]
  D --> E[Layer normalisation]
  E --> F[Mamba block]
  F --> G[Reshape back to B C H W D]
  G --> H[Output feature map]
  • GCM takes a 5D input: batch, channels, height, width, depth.
  • Two residual blocks refine local features first.
  • The spatial map is flattened into a sequence so Mamba can process it.
  • After layer norm, the Mamba block models global context.
  • The sequence is reshaped back into spatial form.

The residual block

flowchart TD
  A[Input features] --> B[Convolution for local features]
  B --> C[Instance normalisation stabilises training]
  C --> D[LeakyReLU adds non-linearity]
  D --> E[Residual addition]
  A --> E
  E --> F[Output equals input plus transform]

The skip connection means the block learns a correction rather than a full transformation, which keeps gradients healthy.

Inside the Mamba block

flowchart TD
  A[Input sequence B L C] --> C[Content branch]
  A --> D[Gating branch]
  C --> E[Linear expansion]
  E --> F[1D convolution]
  F --> G[HardSwish activation]
  G --> H[SSM layer]
  D --> I[Linear expansion]
  I --> J[HardSwish activation]
  H --> K[Hadamard product]
  J --> K
  K --> L[Linear projection]
  L --> M[Output sequence B L C]
  • Branch one produces the content and builds long-range dependency.
  • Branch two produces importance weights — a judgement about how reliable each feature is.
  • They are combined element-wise, so the output carries both the content and an assessment of it.

The selective state-space mechanism

flowchart TD
  A[Input x at step t] --> B[Compute dynamic parameters from x]
  B --> C[Discretise: A bar and B bar]
  C --> D[State update h t equals A bar times h previous plus B bar times x]
  D --> E[Output y t equals C times h t]
  D --> F[Carry h t to the next step]

Four properties worth remembering:

  • Dynamic parameterisation. Δ, B and C are computed from the current input rather than being fixed.
  • Selectivity. Because those parameters depend on the input, the model can choose what to retain and what to ignore.
  • State passing. A state vector h accumulates history, which is how global information travels.
  • Hardware friendliness. Training parallelises; inference runs as an efficient recurrence.

Where it sits in the pipeline

flowchart TD
  A[Prostate MR volume] --> B[CNN encoder extracts local features]
  B --> C[GCM builds global context]
  C --> D[CNN decoder upsamples and segments]
  D --> E[Prostate segmentation result]

The encoder finds edges and texture; GCM establishes how the parts relate to each other as an organ; the decoder combines both to place the boundary.

Why it helps

  1. Global context — long-range spatial dependency becomes representable.
  2. Linear complexity — feasible on 3D volumes, unlike quadratic attention.
  3. Selective attention — important features are amplified, noise suppressed.
  4. Drop-in — it slots into an existing U-Net without redesigning the architecture.
  5. Stable training — residual connections keep gradients flowing.

Specifications

  • Input and output — the same 5D shape, B × C × H × W × D.
  • Sequence length — L = H × W × D.
  • Expansion — 2L, giving each branch its own working space.
  • Activations — HardSwish inside Mamba, LeakyReLU in the residual blocks.
  • Normalisation — instance norm in the residual blocks, layer norm before Mamba.
