定义

阈值方法

阈值方法是一种简单的图像分割技术，通过设置一个或多个阈值将图像像素分为两类或多类。

关键特性：

  • 将灰度图像转换为二值图像
  • 像素值高于阈值设为白色(1)，低于阈值设为黑色(0)
  • 可以是全局阈值或自适应阈值

示例： Otsu阈值法、自适应阈值法

边缘检测滤波器

边缘检测滤波器用于识别图像中像素值急剧变化的区域（边缘）。

关键特性：

  • 通过卷积核计算图像的梯度或导数
  • 输出边缘图，强调轮廓信息
  • 对噪声敏感但能捕捉细节

示例： Sobel滤波器、Canny边缘检测器

机器学习技术

机器学习技术涉及使用算法从数据中自动学习模式和特征。

关键特性：

  • 无需显式编程，自动学习
  • 包括监督学习、无监督学习和强化学习
  • 需要训练数据和模型优化

示例： CNN图像分类、SVM对象检测

相同点

  • 共同应用领域：图像处理、计算机视觉、模式识别
  • 核心目标：从图像中提取有意义信息，简化图像表示
  • 预处理流程：传统方法常作为机器学习的预处理步骤
  • 自动化特性：均可实现不同程度的自动化处理

区别

输出结果 二值图像 边缘图 多样输出
训练需求 无 无 需要训练
计算资源 少 中等 大量
典型应用 文档二值化 轮廓检测 图像分类

总结

技术类型 优势 局限性 适用场景
阈值方法 快速、实现简单 对噪声敏感 简单分割任务

  1. 先用边缘检测进行预处理
  2. 阈值方法辅助区域分割
  3. 机器学习模型进行最终分析和决策

A comparison I wrote while working out where classical image processing ends and machine learning begins.

Definitions

Thresholding

A simple segmentation technique: pick one or more cut-off values and sort every pixel into a class.

  • Converts a greyscale image into a binary one.
  • Pixels above the threshold become white (1), below become black (0).
  • The threshold may be global or adaptive.

Examples: Otsu’s method, adaptive thresholding.

Edge detection filters

Identify regions where pixel values change sharply — the edges.

  • Compute a gradient or derivative through convolution with a kernel.
  • Output an edge map that emphasises contours.
  • Sensitive to noise, but good at detail.

Examples: Sobel, Canny.

Machine learning

Algorithms that learn patterns and features from data automatically.

  • No explicit rule needs to be written.
  • Covers supervised, unsupervised and reinforcement learning.
  • Requires training data and an optimisation procedure.

Examples: CNN classification, SVM detection.

What they share

  • The same domain — image processing, computer vision, pattern recognition.
  • The same goal — extract meaningful information, simplify the representation.
  • A pipeline relationship — the classical methods often serve as preprocessing for the learned ones.
  • Automation — all three run without a human in the loop, to different degrees.

Where they differ

Property Thresholding Edge filters Machine learning
Basis Simple value comparison Gradient / derivative Data-driven learning
Complexity Low Medium High
Adaptability Limited Reasonable Strong
Output Binary image Edge map Varied
Needs training No No Yes
Compute cost Small Medium Large
Typical use Document binarisation Contour detection Image classification

Where each one fits

Thresholding

  • Document scanning and binarisation
  • Simple foreground / background separation
  • Scenes with even illumination

Edge detection

  • Object contour extraction
  • Feature point detection
  • Image sharpening

Machine learning

  • Classification in complex scenes
  • Real-time object detection
  • Autonomous driving vision
  • Medical image analysis

Summary

Approach Strength Limitation Best for
Thresholding Fast, simple to implement Sensitive to noise Simple segmentation
Edge detection Strong at fine detail Can produce false edges Contour extraction
Machine learning High accuracy, generalises Needs a lot of data Complex vision tasks

Using them together

In practice these are rarely alternatives. A common pipeline:

  1. Edge detection as preprocessing.
  2. Thresholding to assist region separation.
  3. A learned model for the final analysis and decision.

Writing this out was useful for a reason I did not expect: the “old” methods have not been replaced. Otsu thresholding still appears inside modern pipelines, and a Sobel operator is still the clearest way to explain what a convolution kernel actually does. The learned model sits on top of them rather than in place of them.
