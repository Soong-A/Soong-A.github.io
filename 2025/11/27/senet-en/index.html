SENet: learning which channel matters

发表于2025-11-27|更新于2026-10-11|English Notes
|浏览量:

7 min read

中文版：SENet：让网络学会看重哪个通道

Notes on Squeeze-and-Excitation Networks.

  • Paper: arXiv:1709.01507
  • Official code: hujie-frank/SENet

Why it mattered

SENet won the ImageNet 2017 classification task:

Top-5 error
Previous best 2.991%
SENet 2.251%
Improvement 0.74 percentage points

The idea: model the interdependencies between feature channels explicitly. Rather than adding a new spatial dimension, it recalibrates the channels it already has — the network learns how important each channel is, then amplifies the useful ones and suppresses the rest.

It is modular, fully differentiable, and drops into existing architectures without redesign.

The four steps

flowchart TD
  A[Input features H x W x C1] --> B[Standard convolution]
  B --> C[Feature map H x W x C2]
  C --> D[Squeeze: global average pooling to 1 x 1 x C2]
  D --> E[Excitation: FC then ReLU then FC then Sigmoid]
  E --> F[Weights 1 x 1 x C2]
  F --> G[Reweight: multiply each channel]
  C --> G
  G --> H[Output H x W x C2]

1. Transformation

uc=vc∗X=∑s=1C1vcs∗xs

An ordinary convolution from H×W×C1 to H×W×C2. Not part of the innovation — just the layer SE attaches to.

2. Squeeze

zc=Fsq(uc)=1H×W∑i=1H∑j=1Wuc(i,j)

Global average pooling reduces H×W×C2 to 1×1×C2. Each channel becomes one number summarising its global response. This is what gives a channel-level receptive field over the entire image.

3. Excitation

s=Fex(z,W)=σ(W2δ(W1z))

A two-layer bottleneck with reduction ratio r=16:

The bottleneck adds non-linearity so the model can fit genuine channel correlations, while keeping the parameter cost low. The sigmoid produces weights in 0–1 — importantly not a softmax, because channels are not mutually exclusive.

4. Reweight

xc~=Fscale(uc,sc)=sc⋅uc

Channel-wise multiplication. Important channels are strengthened, minor ones attenuated.

Where to place the block

Architecture SE position Why
Inception family Inside the module Directly strengthens the feature representation
ResNet family On the residual branch, before the addition Keeps the identity path clean so gradients still flow
Others After a key module Balance cost against benefit

Placing SE on the residual branch rather than after the addition is the detail that matters most — putting it after the merge would scale the identity shortcut too, which defeats the point of having one.

Known variants: SE-BN-Inception, SE-ResNet, SE-ResNeXt, SE-Inception-ResNet-v2.

The cost

Parameters added by one SE block:

Paramssingle=2×C2r

Over a whole network:

Total Params Increase=2r∑s=1SNs⋅Cs2
Symbol Meaning Typical value
C Channel count Varies by layer
r Reduction ratio 16
S Number of stages 4 in ResNet
N_s Blocks in stage s Varies with depth

Measured on ResNet-50:

Metric ResNet-50 SE-ResNet-50 Increase
Parameters ~25M ~27.5M +10%
Compute ~4G FLOPs ~4.2G FLOPs +5%

Because cost scales with C², the final stage — where C reaches 2048 — dominates. Removing SE from some of those last blocks drops the parameter overhead from 10% to about 2% with almost no accuracy loss. A good reminder that where you place a module matters as much as whether you use it.

Why it stayed relevant

SE is essentially the simplest possible attention: no spatial dimension, no extra branch topology, two small dense layers. It reappears constantly — including inside USE-Net for prostate segmentation, which is where I first ran into it.
