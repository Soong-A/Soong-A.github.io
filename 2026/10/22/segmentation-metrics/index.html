Dice、IoU、HD95 医学图像分割评价指标详解：公式、代码与解读误区

发表于2026-10-22|更新于2026-10-25|医学影像

阅读约 7 分钟

读论文时，分割结果几乎都是用 Dice 和 HD95 汇报。两个数字看起来简单，但”怎么算”里藏着很多细节，不同实现可能差好几个点。这篇笔记把常用指标的含义、公式和最容易出错的地方整理在一起。

先分清两类指标

flowchart TD
  A[分割评价指标] --> B[重叠类：衡量区域有多少重合]
  A --> C[距离类：衡量边界差多远]
  B --> D[Dice]
  B --> E[IoU]
  B --> F[精确率 / 召回率]
  C --> G[HD / HD95]
  C --> H[平均表面距离 ASSD]
  • 重叠类回答”区域对了多少”，但对边界的细小偏差不敏感。
  • 距离类回答”边界偏了多远”，但容易被孤立的错误点影响。

只报一类会漏掉信息，所以论文通常两类都给。

重叠类指标

以混淆矩阵的 TP（预测与真实都是前景）、FP（误报）、FN（漏报）表示：

$$\text{Dice} = \frac{2\ \text{TP}}{2\ \text{TP} + \text{FP} + \text{FN}} \qquad \text{IoU} = \frac{\text{TP}}{\text{TP} + \text{FP} + \text{FN}}$$

$$\text{Precision} = \frac{\text{TP}}{\text{TP} + \text{FP}} \qquad \text{Recall} = \frac{\text{TP}}{\text{TP} + \text{FN}}$$

精确率回答“预测为前景的里，有多少是对的”，召回率回答“真实前景里，有多少被找到了”。

几个关系值得记住：

  • Dice 与 IoU 是单调关系：$\text{Dice} = \dfrac{2\ \text{IoU}}{1 + \text{IoU}}$。所以 Dice 为 0.9 对应 IoU 约 0.82，同一个模型的排序在两者之间不会反转。
  • Dice 实际上是 Precision 和 Recall 的调和平均（即 F1）。
  • 用于对比模型时，Precision 和 Recall 能告诉你模型是偏保守还是偏激进：Precision 低说明误报多，Recall 低说明漏掉了目标。

距离类指标：HD95

Hausdorff 距离（HD）取预测边界与真实边界之间所有点距离的最大值。一个孤立的错误点就能让它变得很大，所以实践中更常用 HD95：取第 95 百分位，忽略最差的 5%。

HD95 的单位是体素或毫米，越小越好。要用毫米报告，必须传入体素间距；尤其在层间距明显大于层内分辨率的各向异性数据上，忽略 spacing 会让不同方向的距离失去统一的物理意义。相关背景可以参见 MACM 的动机。

六个最容易出错的细节

  1. 2D 切片平均 vs 3D 体积：对每张切片算 Dice 再平均，和对整个体积算一次 Dice，结果可能差很多，因为含很少目标的切片会被同等对待。要说明采用哪种。
  2. 空预测或空标注：Dice 在两者都为空时是 0/0；HD95 在任一为空时未定义。要明确用 NaN、跳过，还是赋默认值，并在论文里写明。
  3. 体素间距：HD95 必须乘上真实间距，否则数值的单位不统一。
  4. 预处理不一致：评估时必须把预测重采样回原始空间，在原始分辨率上算指标，而不是在裁剪、缩放后的图上算。
  5. 多类别：逐类报告，不要把背景算进平均（原因与 Dice Loss 里的情况 相同）。
  6. 只报告平均值：分割表现常常有几个失败病例拖累。至少同时给出标准差、中位数或箱线图，对比两个模型时用配对检验（如 Wilcoxon 符号秩检验）。

怎样选择报告哪些指标

场景 推荐
通用分割对比 Dice + HD95
关心误报和漏报的平衡 再加 Precision 和 Recall
小目标（病灶） Dice 会很不稳定，补充 HD95 和逐病例结果
临床勾画、放疗计划 补充距离类指标，直接表达边界偏差的毫米数

指标和训练目标不必一致，但要知道它们的盲区：Dice Loss 优化重叠，不直接约束边界；改进特征融合（例如 AFFM 抑制背景噪声）可能改善 HD95，但仍需用实验单独验证。

小结

  • Dice 和 IoU 回答”重合了多少”，HD95 回答”边界偏了多远”。
  • 同一个模型，换一种平均方式或忽略体素间距，数字就会变。
  • 对比论文数字之前，先确认它们的口径一致。

7 min read

Segmentation papers almost always report Dice and HD95. The two numbers look simple, but how they are computed hides many details, and different implementations can differ by several points. These notes collect what the common metrics mean, their formulas, and where people trip.

Two families of metrics

flowchart TD
  A[Segmentation metrics] --> B[Overlap: how much the regions coincide]
  A --> C[Distance: how far the boundaries are apart]
  B --> D[Dice]
  B --> E[IoU]
  B --> F[Precision / recall]
  C --> G[HD / HD95]
  C --> H[Average surface distance ASSD]
  • Overlap answers “how much of the region is right” but barely notices small boundary errors.
  • Distance answers “how far off is the boundary” but is easily swayed by isolated bad points.

Reporting only one family loses information, so papers usually give both.

Overlap metrics

Using TP (foreground in both), FP (false alarm) and FN (miss):

$$\text{Dice} = \frac{2\ \text{TP}}{2\ \text{TP} + \text{FP} + \text{FN}} \qquad \text{IoU} = \frac{\text{TP}}{\text{TP} + \text{FP} + \text{FN}}$$

$$\text{Precision} = \frac{\text{TP}}{\text{TP} + \text{FP}} \qquad \text{Recall} = \frac{\text{TP}}{\text{TP} + \text{FN}}$$

Precision asks how much of what you predicted is right; recall asks how much of the true foreground you found.

Worth remembering:

  • Dice and IoU are monotonically related: $\text{Dice} = \dfrac{2\ \text{IoU}}{1 + \text{IoU}}$. A Dice of 0.9 is an IoU of about 0.82, and model rankings do not flip between them.
  • Dice is the harmonic mean of precision and recall (that is, F1).
  • Precision and recall show whether a model is conservative or aggressive: low precision means many false alarms, low recall means missed targets.

Distance metric: HD95

The Hausdorff distance (HD) is the maximum distance between predicted and true boundary points. One isolated bad point can make it huge, so HD95 — the 95th percentile, ignoring the worst 5% — is more common.

HD95 is in voxels or millimetres, and lower is better. To report millimetres you must pass the voxel spacing; on anisotropic data (such as prostate MR with 3 mm slices and 0.5 mm in-plane, the motivation for MACM) numbers without spacing have no physical meaning.

Six details that go wrong

  1. 2D slice average vs 3D volume — averaging per-slice Dice and computing one Dice on the volume can differ a lot, since slices with little target count equally. State which one you use.
  2. Empty prediction or mask — Dice is 0/0 when both are empty; HD95 is undefined when either is. Decide between NaN, skipping, or a default, and say so.
  3. Voxel spacing — HD95 must use the real spacing, or units are inconsistent.
  4. Inconsistent preprocessing — resample predictions back to the original space and compute metrics at original resolution, not on cropped or rescaled images.
  5. Multi-class — report per class, and keep background out of the average (the same reason as in Dice Loss).
  6. Mean only — a few failed cases often drag the result. Give the standard deviation, median or a box plot, and compare two models with a paired test such as Wilcoxon signed-rank.

Which metrics to report

Setting Recommended
General model comparison Dice + HD95
Balance of false alarms and misses Add precision and recall
Small targets (lesions) Dice is unstable; add HD95 and per-case results
Clinical contouring, radiotherapy planning Distance metrics are closer to what matters; a few mm of boundary error counts more than overlap

Metrics need not match the training objective, but know their blind spots: Dice Loss optimises overlap and does not constrain the boundary directly, which is why improvements such as AFFM suppressing background noise often show up in HD95.

Summary

  • Dice and IoU say how much overlaps; HD95 says how far the boundary is off.
  • For the same model, a different averaging scheme or ignoring spacing changes the number.
  • Before comparing with a paper’s numbers, confirm the conventions match.
