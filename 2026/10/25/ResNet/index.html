ResNet 残差网络超详细入门：从退化问题到 BasicBlock 与 Bottleneck

发表于2026-10-25|更新于2026-10-25|经典网络

阅读约 22 分钟 · 建议边看图边手算

如果只记一句话，可以先记住：ResNet 给信息修了一条“直达电梯”。普通网络要求每一层都重新加工输入；ResNet 允许输入绕过若干层，直接送到后面，再和新学到的变化量相加。

这条看起来只是“一根线”的结构，解决了深层网络很难优化的问题。后来的 DenseNet、SENet、Res2Net 以及大量医学图像分割网络，都在它的思想上继续发展。

阅读前只需要知道三件事

不熟悉下面的词也没关系，先用最朴素的理解即可：

  • 卷积层（Conv）： 用许多小滤镜提取边缘、纹理、形状等特征。
  • 特征图（feature map）： 一层网络处理后的数据。它不一定是能直接看懂的图片，但仍然有高度、宽度和通道数。
  • 反向传播： 模型算错后，把“错了多少”从输出往输入方向传，用它更新每一层的参数。

本文会频繁出现 $N \times C \times H \times W$：$N$ 是一批图片的数量，$C$ 是通道数，$H$ 和 $W$ 是高与宽。

论文名片

  • 论文： Deep Residual Learning for Image Recognition
  • 作者： Kaiming He、Xiangyu Zhang、Shaoqing Ren、Jian Sun（MSRA）
  • 会议： CVPR 2016
  • 论文地址： arXiv:1512.03385
  • 核心贡献： 用残差连接稳定训练非常深的卷积网络，并构建了最高 152 层的 ImageNet 模型。

一、为什么当年大家想把网络做深

一张图片进入卷积网络后，浅层通常学习简单特征，深层逐步组合出复杂概念：

直觉上，层数越多，模型能完成的加工步骤越多，应该更容易表达复杂函数。但“能表达”不等于“能训练出来”。在 ResNet 之前，人们发现普通网络加深到一定程度后，效果反而变差。

1. 先区分三个容易混淆的问题

问题 训练集误差 测试集误差 直观解释
过拟合 很低 很高 训练题背得太熟，换题不会
梯度消失 / 爆炸 可能降不动 通常也差 误差信号传不到前层，或数值失控
退化问题 深网比浅网更高 深网也更高 深网理论上更强，却连浅网的解都学不到

ResNet 论文强调的是第三种：退化问题（degradation problem）。

论文在 CIFAR-10 上比较了 20 层和 56 层的普通卷积网络。56 层网络不仅测试误差更高，连训练误差都更高。因此不能把原因简单归结为过拟合。

图中是帮助理解的概念曲线，不是论文实验数据的逐点复刻。重点是看“训练误差”的相对关系。

2. 一个看似简单、实际上很关键的逻辑

假设已经有一个训练好的 20 层网络。现在给它再加 36 层，要得到一个 56 层网络。新加的 36 层什么都不改变，只把输入原样输出，不就至少能保持 20 层网络的效果吗？

“输入什么就输出什么”叫做恒等映射（identity mapping）：

$$H(x) = x$$

从函数表达能力看，56 层网络确实包含这个解。问题是：让几十个“卷积 + 非线性激活”层共同精确拼出 $H(x)=x$，对优化器并不容易。

这就是 ResNet 的出发点：既然深层网络很难自己学会“什么也别做”，那就把“什么也别做”直接写进结构里。

二、残差学习到底在学什么

先把字母解释清楚：

符号 含义
$x$ 残差块的输入
$H(x)$ 希望这个块最终得到的理想输出
$F(x)$ 主分支真正需要学习的“变化量”
$y$ 残差块的实际输出

普通网络直接学习：

$$y = H(x)$$

ResNet 改成：

$$\begin{aligned} F(x) &= H(x) - x \cr y &= F(x) + x \end{aligned}$$

这里的“残差”就是“目标与输入之间还差多少”。

1. 用修图来理解残差

假设输入 $x$ 是一张曝光稍暗的照片，理想输出 $H(x)$ 是调整好的照片。

普通网络的任务是：从头生成整张调整后的照片。

残差网络的任务是：只生成“哪里提亮多少、哪里增加多少对比度”这张修改清单，然后把修改清单加回原图。

如果原图已经很好：

$$H(x) \approx x \quad \Longrightarrow \quad F(x) = H(x) - x \approx 0$$

模型只要把主分支学到接近 0，就能保留输入。让若干层输出接近 0，通常比让它们共同精确复现 $x$ 容易。

2. 用一个只有数字的例子理解

假设某个特征是 $x = 10$，理想输出是 $H(x) = 10.5$。

  • 普通学习： 直接把 10 变成 10.5。
  • 残差学习： 只学习 $F(x) = 10.5 - 10 = 0.5$，最后 $0.5 + 10 = 10.5$。

如果理想输出正好是 10：

  • 普通学习： 一串层必须共同实现 $H(10) = 10$。
  • 残差学习： 主分支输出 $F(10) = 0$ 即可。

注意，残差不是“预测误差”或“损失值”。它是特征变换前后的差值，在网络内部被主动学习。

三、那条捷径为什么能帮助梯度传播

残差块有两条路：

  1. 主分支： 经过卷积、BN、ReLU，得到 $F(x)$；
  2. 捷径分支： 输入 $x$ 原样绕过去。

最后把两路按元素相加：

$$y = F(x) + x$$

这里的“相加”要求两边形状完全相同。例如主分支和捷径都必须是 $N \times 64 \times 56 \times 56$。如果形状不同，后面会讲怎么处理。

1. 先理解普通深层网络的梯度

反向传播依赖链式法则。把很多层串在一起时，梯度会不断相乘：

$$\frac{\partial L}{\partial x_0} = g_1 \cdot g_2 \cdots g_n = \prod_{i=1}^{n} g_i$$

其中 $g_i$ 是第 $i$ 段的局部梯度。

如果每一段大约是 $0.8$，连续乘 20 次：

$$0.8^{20} \approx 0.0115$$

传到前面的信号已经很小。如果每一段都大于 1，又可能越乘越大。这只是直觉示例，真实网络中的梯度是张量而不是单个数字，但问题本质相似。

2. 残差块多出来一个“1”

对 $y = F(x) + x$ 求导，可写成：

$$\frac{\partial y}{\partial x} = \frac{\partial F(x)}{\partial x} + 1$$

因此：

$$\frac{\partial L}{\partial x} = \frac{\partial L}{\partial y} \cdot \left( \frac{\partial F(x)}{\partial x} + 1 \right)$$

这个 $1$ 来自捷径上的 $x$。即使主分支的局部梯度很小，仍有一部分梯度可以沿着捷径直接向前传播。

更完整地说，跨过多个残差块后，浅层特征不仅通过层层变换传播，还能通过一连串加法路径抵达后层。ResNet 不是让梯度永远不会消失，而是显著改善了深层网络的优化条件。

3. 为什么要“相加”，而不是“拼接”

ResNet 使用相加，所以通道数不膨胀，计算量容易控制；而 DenseNet 使用通道拼接，让后层显式看到之前所有层的特征。二者都是捷径，但信息融合方式不同。

四、BasicBlock：ResNet-18 和 ResNet-34 的积木

原始 ResNet v1 的 BasicBlock 主分支包含两个 3×3 卷积：

flowchart LR
  X["输入 x"] --> C1["3×3 Conv"]
  C1 --> B1["BN"] --> R1["ReLU"]
  R1 --> C2["3×3 Conv"] --> B2["BN"]
  B2 --> ADD(("逐元素相加"))
  X -- "恒等捷径" --> ADD
  ADD --> R2["ReLU"] --> Y["输出 y"]

把顺序背成一句话：

第二个 BN 后面不能先做 ReLU。主分支必须保留正值和负值，再与 $x$ 相加；否则主分支就不能自由地“增加或抵消”输入。

这里不是把所有数加成一个数，而是对应位置逐个相加：

$$y_{n,c,h,w} = F_{n,c,h,w} + x_{n,c,h,w}$$

其中 $F$ 是主分支的输出 $F(x)$。

五、维度不一样时，捷径怎么办

网络进入新的 stage 时，常做两件事：

  • 高和宽减半，例如 56×56 → 28×28；
  • 通道增加，例如 64 → 128。

此时：

形状不同，不能相加。解决办法是在捷径上放一个 1×1 卷积，并使用 stride=2：

flowchart LR
  X["x: 64×56×56"] --> MAIN["主分支<br/>3×3 Conv, stride=2"]
  MAIN --> FM["F(x): 128×28×28"] --> ADD(("+"))
  X --> PROJ["捷径<br/>1×1 Conv, stride=2"]
  PROJ --> ID["投影后: 128×28×28"] --> ADD
  ADD --> Y["y: 128×28×28"]

这个 1×1 卷积叫投影捷径（projection shortcut）。它同时完成：

  1. 用 stride 2 缩小空间尺寸；
  2. 用不同数量的卷积核改变通道数；
  3. 让主分支和捷径能够相加。

论文还讨论了补零扩通道等方案。工程里最常见的是：只有尺寸或通道变化时才用 1×1 投影，其他块保留无参数的恒等捷径。

六、Bottleneck：ResNet-50/101/152 为什么不直接堆 3×3

通道很多时，两个 3×3 卷积非常昂贵。Bottleneck（瓶颈块）用三个卷积：

典型例子：

“瓶颈”不是说信息一定被严重丢失，而是中间通道数像瓶子中间一样变窄，从而把最贵的 3×3 卷积放在较少的通道上。

1. 为什么 1×1 卷积能改变通道

一个 1×1 卷积核只看同一空间位置，但会同时读取所有输入通道。若输入有 256 个通道，准备 64 个 1×1 卷积核，就能在每个像素位置把 256 维信息混合成 64 维。

它不负责看邻居，主要负责通道混合与升降维。

2. 参数量手算

卷积参数量（忽略偏置）是：

$$\text{params} = k_h \times k_w \times C_{\text{in}} \times C_{\text{out}}$$

如果始终在 256 通道上做两个 3×3：

$$2 \times (3 \times 3 \times 256 \times 256) = 1{,}179{,}648$$

Bottleneck 的主分支：

卷积 参数量计算 参数量
1×1 降维 $1 \times 1 \times 256 \times 64$ 16,384
3×3 处理 $3 \times 3 \times 64 \times 64$ 36,864
1×1 升维 $1 \times 1 \times 64 \times 256$ 16,384
合计 69,632

这个对比是在说明“通道压缩为什么省参数”，不是说两种块的层数完全相同。Bottleneck 有 3 个卷积层，BasicBlock 有 2 个。

3. expansion = 4 是什么意思

标准 Bottleneck 的最后输出通道是中间通道的 4 倍：

所以 PyTorch 实现里会看到 expansion = 4。ResNet-50 最后一个 stage 的输出是 2048 通道，而 ResNet-18 最后是 512 通道。

v2 把 BN 和 ReLU 放到卷积前，相加之后不立刻激活。这样多个块串起来时，捷径主干上更接近纯粹的恒等映射，信息和梯度传播更直接。

  • v1/v2 描述算子的排列方式；
  • BasicBlock/Bottleneck 描述主分支的卷积结构。

九、一步步读懂 PyTorch 的 BasicBlock

代码里五个常见疑问

1. 为什么卷积写 bias=False？ 之后的 BatchNorm 自带可学习偏移 beta，卷积偏置会被 BN 的减均值操作抵消，保留它通常是冗余的。

2. 为什么第一个卷积用 stride，第二个固定为 1？ 每个 stage 只需下采样一次。第一层先把尺寸对齐，后续计算都在较小特征图上完成。

3. 为什么是 out + identity，不是拼接？ 残差公式就是逐元素相加，并且相加不会增加通道数。

4. 为什么不推荐 out += identity？ 原地修改可能覆盖自动求导仍需使用的中间值。普通加法更稳妥。

5. nn.Identity() 有什么用？ 它原样返回输入，使代码不必在 forward 里写两套分支。

十、初学者最容易犯的七个错误

错误 1：把 residual 当成分类误差

$F(x)=H(x)-x$ 是块内部的特征差值；训练损失则比较最终预测和标签。它们不是一回事。

错误 2：认为捷径完全没有计算

形状不变时捷径是 Identity；形状变化时通常有 1×1 卷积和 BN。

错误 3：把相加写成通道拼接

torch.cat([out, identity], dim=1) 会把通道翻倍，这更像 DenseNet/U-Net 的连接方式，不是标准 ResNet。

错误 4：两路形状不一致就相加

看到 “The size of tensor a must match…” 一类报错，先打印两路的 shape，检查通道、stride 和 padding。

错误 5：把 ResNet 理解为只解决梯度消失

它确实改善梯度传播，但原论文更直接瞄准的是深层普通网络的优化退化。BN、合理初始化等手段已经缓解了朴素的梯度爆炸/消失，残差结构进一步让深网更易优化。

错误 6：认为层数越深一定越适合自己的任务

深网计算更慢、显存更大，也更依赖数据量和训练策略。小数据任务上，预训练 ResNet-18/34 有时比从头训练 ResNet-101 更可靠。

错误 7：忘记输入通道数

ImageNet 预训练模型通常接收 RGB 三通道。灰度医学图像要么复制为三通道，要么改第一层卷积，并考虑预训练权重如何迁移。

十一、在医学图像分割里怎样使用 ResNet

U-Net 的编码器本质上负责不断下采样并提取多尺度特征，因此常把普通卷积编码器替换成预训练 ResNet：

这样做有两个常见收益：

  • ImageNet 预训练权重能提供稳定的边缘、纹理等低层特征，对标注稀缺的医学数据很有价值；
  • 残差连接让编码器加深时仍较容易训练。

但要留意输出步长。分类 ResNet 最深特征通常只有输入的 $1/32$，小病灶可能被下采样得过狠。分割模型经常取消后面一次下采样、改用空洞卷积，或依赖强解码器与高分辨率跳跃连接。

十二、从 ResNet 看懂后来的网络

把一个残差块拆成“主分支、捷径、融合方式”三部分，许多后续工作就很好理解：

工作 改了哪里 一句话理解
DenseNet 融合方式 相加改成通道拼接，保留所有旧特征
SENet 主分支出口 相加前为不同通道学习重要性权重
Res2Net 主分支内部 在一个块内制造多尺度层级残差
ResNeXt 主分支内部 用并行分组变换增加“基数”
ResNet v2 算子顺序 预激活让恒等捷径更干净

十三、三道自测题

先自己回答，再展开答案。

1. 如果残差块最理想的行为是什么都不改变，主分支应该学到什么？

应该学到 $F(x)=0$，这样 $y=F(x)+x=x$。

2. 输入是 64×56×56，主分支输出是 128×28×28，为什么不能直接相加？

逐元素相加要求通道、高、宽完全一致。应在捷径上用带 stride=2 的 1×1 卷积，把输入投影成 128×28×28。

3. ResNet-50 为什么用 Bottleneck 而不是 BasicBlock？

深层 stage 的通道数很大。Bottleneck 先用 1×1 降通道，让昂贵的 3×3 卷积在窄通道上计算，再升回输出通道，能以可控的参数量和计算量堆得更深。

最后用一张清单复习

  • ResNet 要解决的是：普通深层网络出现训练退化，不是单纯过拟合。
  • 普通块直接学 $H(x)$；残差块学习 $F(x)=H(x)-x$，输出是 $F(x)+x$。
  • 当理想映射接近恒等时，学习 $F(x)\approx0$ 更容易。
  • 捷径为前向信息和反向梯度提供了直接路径。
  • BasicBlock 用两个 3×3，服务于 ResNet-18/34。
  • Bottleneck 用 1×1 → 3×3 → 1×1，服务于 ResNet-50/101/152。
  • 两路形状不一致时，用 1×1 投影捷径对齐。
  • “残差相加”与 U-Net/DenseNet 的“通道拼接”不是同一件事。

If you remember only one sentence, remember this: ResNet gives information a direct elevator. A plain network asks every layer to process its input again. ResNet lets the input bypass several layers, travel straight to the other side, and then adds it to the newly learned change.

That structure looks like “just one extra line”, but it made very deep networks much easier to optimise. Later models such as DenseNet, SENet, Res2Net and many medical-image segmentation networks all develop this idea further.

Three things to know before reading

It is fine if these terms are new. Start with their simplest meanings:

  • Convolutional layer (Conv): uses many small filters to extract edges, textures, shapes and other features.
  • Feature map: the data produced by a layer. It may not look like an ordinary image, but it still has height, width and channels.
  • Backpropagation: after the model makes an error, it sends information about that error from the output towards the input and uses it to update every layer.

This article repeatedly uses $N \times C \times H \times W$: $N$ is the number of images in a batch, $C$ the number of channels, and $H$ and $W$ the height and width.

Paper at a glance

  • Paper: Deep Residual Learning for Image Recognition
  • Authors: Kaiming He, Xiangyu Zhang, Shaoqing Ren and Jian Sun (MSRA)
  • Venue: CVPR 2016
  • Paper: arXiv:1512.03385
  • Main contribution: residual connections made very deep convolutional networks stable to train and enabled ImageNet models as deep as 152 layers.

1. Why did researchers want deeper networks?

When an image enters a convolutional network, early layers usually learn simple features and deeper layers combine them into more complex concepts:

More layers provide more processing steps, so a deeper model should be able to represent more complex functions. But being able to represent a function is not the same as being able to learn it. Before ResNet, researchers found that a plain network often became worse after it passed a certain depth.

1.1 Separate three easily confused problems

Problem Training error Test error Intuition
Overfitting very low high memorises the exercises but fails on new ones
Vanishing/exploding gradients may barely decrease usually poor the error signal cannot reach early layers, or its magnitude becomes unstable
Degradation a deep network is worse than a shallow one also worse the deep model is more expressive in theory but cannot even learn the shallow model’s solution

The ResNet paper focuses on the third problem: the degradation problem.

On CIFAR-10, the paper compared 20-layer and 56-layer plain convolutional networks. The 56-layer network had not only a higher test error but also a higher training error. The result therefore cannot be explained simply as overfitting.

The curves are conceptual rather than a point-by-point copy of the paper’s experiment. The important part is the relative training error.

1.2 A simple but crucial argument

Suppose we already have a trained 20-layer network. We add 36 layers to make it 56 layers. If the 36 new layers change nothing and simply return their input, should the deeper network not at least match the 20-layer one?

“Output exactly what you receive” is the identity mapping:

$$H(x) = x$$

The 56-layer model contains this solution in terms of representational capacity. The difficulty is optimisation: asking dozens of convolution and nonlinear activation layers to reproduce $H(x)=x$ exactly is surprisingly hard.

This is the starting point of ResNet: if a deep stack has trouble learning to do nothing, put “do nothing” directly into the architecture.

2. What does residual learning actually learn?

First, define the symbols:

Symbol Meaning
$x$ input to a residual block
$H(x)$ ideal output the block should produce
$F(x)$ the change the main branch must learn
$y$ actual output of the residual block

A plain block learns:

$$y = H(x)$$

ResNet rewrites the task as:

$$\begin{aligned} F(x) &= H(x) - x \cr y &= F(x) + x \end{aligned}$$

The “residual” is what is still missing between the input and the desired output.

2.1 Think of photo editing

Suppose $x$ is a slightly underexposed photograph and $H(x)$ is the corrected photograph.

A plain network must generate the entire corrected image.

A residual network only needs to generate an edit list describing where to brighten and where to increase contrast, then add that list back to the original image.

If the input is already good:

$$H(x) \approx x \quad \Longrightarrow \quad F(x) = H(x)-x \approx 0$$

The model can preserve its input simply by making the main branch output nearly zero. That is usually easier than asking several layers to reproduce $x$ exactly.

2.2 A numerical example

Suppose a feature has value $x=10$ and its ideal output is $H(x)=10.5$.

  • Plain learning: directly transform 10 into 10.5.
  • Residual learning: learn only $F(x)=10.5-10=0.5$, then compute $0.5+10=10.5$.

If the desired output is exactly 10:

  • Plain learning: the complete stack must implement $H(10)=10$.
  • Residual learning: the main branch only needs to output $F(10)=0$.

The residual here is not a prediction error or a loss value. It is the difference between input and output features, deliberately learned inside the network.

3. Why does the shortcut help gradients flow?

A residual block has two paths:

  1. Main branch: convolution, BN and ReLU produce $F(x)$.
  2. Shortcut branch: the original $x$ bypasses those operations.

The two paths are added element by element:

$$y = F(x)+x$$

Addition requires identical shapes. For example, both branches must have shape $N \times 64 \times 56 \times 56$. We will handle mismatched shapes later.

3.1 Gradients in an ordinary deep network

Backpropagation follows the chain rule. Across a long sequence of layers, local gradients keep multiplying:

$$\frac{\partial L}{\partial x_0}=g_1g_2\cdots g_n=\prod_{i=1}^{n}g_i$$

If every segment is approximately 0.8, then after 20 multiplications:

$$0.8^{20}\approx0.0115$$

Only a very small signal reaches early layers. If the factors are repeatedly larger than one, the gradient may instead grow without control. Real gradients are tensors rather than single numbers, but the intuition is the same.

3.2 A residual block contributes an extra “1”

Differentiate $y=F(x)+x$:

$$\frac{\partial y}{\partial x}=\frac{\partial F(x)}{\partial x}+1$$

Therefore:

$$\frac{\partial L}{\partial x}=\frac{\partial L}{\partial y}\left(\frac{\partial F(x)}{\partial x}+1\right)$$

The $1$ comes from the shortcut. Even if the local gradient through the main branch is small, part of the gradient can still travel directly through the shortcut.

Across many residual blocks, shallow features reach deeper layers through both transformed paths and a sequence of additive shortcuts. ResNet does not make vanishing gradients mathematically impossible, but it greatly improves the optimisation conditions of deep networks.

3.3 Why addition rather than concatenation?

ResNet uses addition, so channel counts do not keep growing and computation stays controlled. DenseNet uses channel concatenation so later layers can explicitly access every earlier feature. Both are shortcuts, but they fuse information differently.

4. BasicBlock: the building block of ResNet-18 and ResNet-34

The main branch of the original ResNet v1 BasicBlock contains two 3×3 convolutions:

flowchart LR
  X["input x"] --> C1["3×3 Conv"]
  C1 --> B1["BN"] --> R1["ReLU"]
  R1 --> C2["3×3 Conv"] --> B2["BN"]
  B2 --> ADD(("element-wise add"))
  X -- "identity shortcut" --> ADD
  ADD --> R2["ReLU"] --> Y["output y"]

Memorise the order as one line:

There is no ReLU immediately after the second BN. The main branch must retain both positive and negative values before it is added to $x$; otherwise it cannot freely increase or cancel parts of the input.

5. What if the dimensions do not match?

When a network enters a new stage it commonly does two things:

  • halves height and width, for example 56×56 → 28×28;
  • increases channels, for example 64 → 128.

Now the branches have different shapes:

They cannot be added. The usual solution is a 1×1 convolution with stride=2 on the shortcut:

flowchart LR
  X["x: 64×56×56"] --> MAIN["main branch<br/>3×3 Conv, stride=2"]
  MAIN --> FM["F(x): 128×28×28"] --> ADD(("+"))
  X --> PROJ["shortcut<br/>1×1 Conv, stride=2"]
  PROJ --> ID["projected: 128×28×28"] --> ADD
  ADD --> Y["y: 128×28×28"]

This is a projection shortcut. It:

  1. uses stride 2 to reduce the spatial size;
  2. uses a new set of filters to change the number of channels;
  3. gives both branches matching shapes so they can be added.

The paper also discusses zero-padding the channel dimension. In practice, the common rule is: use a 1×1 projection only when spatial size or channel count changes; otherwise keep the parameter-free identity shortcut.

6. Bottleneck: why ResNet-50/101/152 do not simply stack 3×3 layers

Two 3×3 convolutions become expensive when the channel count is large. A Bottleneck uses three convolutions:

A typical example is:

“Bottleneck” does not mean that useful information must be destroyed. It means the middle channel dimension narrows like the neck of a bottle, allowing the expensive 3×3 convolution to run on fewer channels.

6.1 How can a 1×1 convolution change channels?

A 1×1 kernel examines only one spatial position, but it reads every input channel at that position. Given 256 input channels, 64 different 1×1 kernels mix the 256-dimensional vector into 64 output dimensions at every pixel.

It does not inspect neighbouring pixels. Its main jobs are channel mixing and dimensionality reduction or expansion.

6.2 Calculate the parameter count

Ignoring bias, a convolution has:

$$\text{params}=k_hk_wC_{\text{in}}C_{\text{out}}$$

Two 3×3 convolutions operating entirely at 256 channels require:

$$2(3\times3\times256\times256)=1{,}179{,}648$$

The Bottleneck main branch requires:

Convolution Calculation Parameters
1×1 reduction $1\times1\times256\times64$ 16,384
3×3 processing $3\times3\times64\times64$ 36,864
1×1 expansion $1\times1\times64\times256$ 16,384
Total 69,632

This comparison demonstrates why channel compression saves parameters; it does not claim the two blocks have the same number of layers. A Bottleneck has three convolutions and a BasicBlock has two.

6.3 What does expansion = 4 mean?

The output of a standard Bottleneck has four times as many channels as its middle representation:

That is why PyTorch sets expansion = 4. The final stage of ResNet-50 outputs 2048 channels, while ResNet-18 ends with 512.

Layer counting normally includes weighted convolutional layers and the final fully connected layer, but excludes BN, ReLU, pooling and element-wise additions. A BasicBlock therefore contributes two “layers” even though its computation graph contains more operations.

The later paper Identity Mappings in Deep Residual Networks proposed pre-activation ResNet v2:

V2 moves BN and ReLU before each convolution and applies no immediate activation after addition. Across many blocks, the shortcut backbone is therefore closer to a pure identity mapping, giving information and gradients a more direct route.

Do not confuse v1/v2 with BasicBlock/Bottleneck:

  • v1/v2 describe the ordering of operations;
  • BasicBlock/Bottleneck describe the convolutional structure of the main branch.

9. Read a PyTorch BasicBlock step by step

Five common questions about the code

1. Why does the convolution use bias=False? The following BatchNorm already has a learnable offset beta, and BN’s centring operation cancels the convolutional bias. Keeping both is usually redundant.

2. Why does the first convolution use stride, while the second always uses 1? Each stage only needs to downsample once. The first layer aligns the size, then the remaining computation runs on the smaller feature map.

3. Why out + identity rather than concatenation? The residual formula uses element-wise addition, which does not increase the channel count.

4. Why avoid out += identity? An in-place operation can overwrite an intermediate value still needed by autograd. Ordinary addition is safer.

5. What is nn.Identity() for? It returns its input unchanged, so forward does not need two different code paths.

10. Seven mistakes beginners often make

Mistake 1: treating the residual as the classification error

$F(x)=H(x)-x$ is an internal feature difference. The training loss compares the final prediction with the target label. They are not the same thing.

Mistake 2: assuming the shortcut always performs no computation

When the shape is unchanged the shortcut is Identity; when the shape changes it commonly contains a 1×1 convolution and BN.

Mistake 3: replacing addition with channel concatenation

torch.cat([out, identity], dim=1) doubles the channels. That resembles a DenseNet or U-Net connection, not a standard ResNet shortcut.

Mistake 4: adding branches with incompatible shapes

If you see an error such as “The size of tensor a must match…”, print the shapes of both branches and check the channel count, stride and padding.

Mistake 5: thinking ResNet only solves vanishing gradients

It does improve gradient flow, but the original paper directly targeted the optimisation degradation of deep plain networks. BN and sensible initialisation had already reduced basic exploding/vanishing-gradient problems; residual structure made the deeper optimisation landscape easier still.

Mistake 6: assuming deeper is always better for your task

Deeper networks are slower, use more memory and depend more strongly on data volume and training strategy. On a small dataset, a pretrained ResNet-18/34 can be more reliable than training ResNet-101 from scratch.

Mistake 7: forgetting the input channel count

ImageNet-pretrained models normally expect three RGB channels. For grayscale medical images, either repeat the image across three channels or modify the first convolution and decide how to transfer its pretrained weights.

11. Using ResNet in medical-image segmentation

A U-Net encoder repeatedly downsamples and extracts multi-scale features, so its ordinary convolutional encoder is often replaced with a pretrained ResNet:

This commonly provides two benefits:

  • ImageNet pretraining supplies stable low-level edge and texture features, which are valuable when medical labels are scarce.
  • Residual connections keep a deeper encoder reasonably easy to train.

Watch the output stride. The deepest feature map of a classification ResNet is normally only $1/32$ of the input resolution, which can erase tiny lesions. Segmentation models often remove a late downsampling step, replace it with dilated convolution, or rely on a strong decoder and high-resolution skip connections.

12. Use ResNet to understand later networks

Once a residual block is separated into its main branch, shortcut and fusion operation, many later models become easier to read:

Work What changed? One-sentence interpretation
DenseNet fusion replace addition with channel concatenation and preserve every older feature
SENet end of main branch learn an importance weight for each channel before addition
Res2Net inside main branch create hierarchical multi-scale residuals inside one block
ResNeXt inside main branch use parallel grouped transformations to increase cardinality
ResNet v2 operation order pre-activation keeps the identity shortcut cleaner

13. Three self-check questions

Answer each one before expanding it.

1. If the ideal behaviour of a residual block is to change nothing

It should learn $F(x)=0$, so $y=F(x)+x=x$.

2. The input is 64×56×56 and the main-branch output is 128×28×28. Why can they not be added directly?

Element-wise addition requires identical channel, height and width dimensions. Use a 1×1 convolution with stride=2 on the shortcut to project the input to 128×28×28.

3. Why does ResNet-50 use Bottleneck rather than BasicBlock?

Later stages have many channels. Bottleneck first reduces the channel count with a 1×1 convolution, runs the expensive 3×3 convolution in the narrow representation, and then expands again. This permits much greater depth at manageable parameter and compute cost.

Final review checklist

  • ResNet addresses training degradation in deep plain networks, not merely overfitting.
  • A plain block learns $H(x)$; a residual block learns $F(x)=H(x)-x$ and outputs $F(x)+x$.
  • When the ideal mapping is close to identity, learning $F(x)\approx0$ is easier.
  • Shortcuts provide direct routes for forward information and backward gradients.
  • BasicBlock uses two 3×3 convolutions in ResNet-18/34.
  • Bottleneck uses 1×1 → 3×3 → 1×1 in ResNet-50/101/152.
  • When the two branches have different shapes, a 1×1 projection shortcut aligns them.
  • Residual addition is not the same operation as channel concatenation in U-Net or DenseNet.
